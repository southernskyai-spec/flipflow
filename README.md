# FlipFlow API

Reseller Intelligence & Opportunity Scoring Engine — a FastAPI service that analyzes a potential resale flip (buy price, estimated resale price, condition, fees, demand/sell-speed/confidence estimates) and returns a structured breakdown: projected profit, ROI, a weighted opportunity score, a buy/pass verdict, the maximum price you should pay to hit a target ROI, plus supporting reasons and risk flags.

## How scoring works

`opportunity_score` is a weighted blend (0-100):

| Factor | Weight |
|---|---|
| Profit score | 30% |
| ROI score | 25% |
| Demand score | 15% |
| Sell-speed score | 10% |
| Confidence score | 10% |
| Condition score | 10% |

The verdict (`STRONG BUY` / `BUY` / `NEGOTIATE` / `CAUTION` / `PASS`) is then derived from that score plus the raw profit and ROI figures. `max_buy_price` is solved algebraically from the target ROI (default 40%) and fixed costs, so you know your ceiling before you buy.

## Setup

```
pip install -r requirements.txt
```

## Running it

```
uvicorn flipflow:app --reload
```

Server runs at `http://127.0.0.1:8000`. Interactive API docs (auto-generated by FastAPI) are at `http://127.0.0.1:8000/docs`.

## Endpoints

- `GET /` — status/info
- `GET /health` — health check
- `POST /analyze` — the main endpoint. Example request:

```json
{
  "title": "iPhone 12 64GB",
  "asking_price": 150,
  "estimated_resale_price": 260,
  "condition": "good",
  "estimated_fees": 20,
  "estimated_shipping": 10,
  "demand_score": 75,
  "sell_speed_score": 70,
  "confidence_score": 65
}
```

Example response:

```json
{
  "title": "iPhone 12 64GB",
  "projected_profit": 80.0,
  "roi_percent": 44.4,
  "opportunity_score": 48.1,
  "verdict": "CAUTION",
  "max_buy_price": 155.71,
  "reasons": ["Projected to be profitable.", "Demand appears strong.", "Item may sell quickly."],
  "risk_flags": []
}
```
